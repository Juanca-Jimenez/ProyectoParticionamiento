# MANUAL DE USUARIO

## Uso de la interfaz
1. Ingrese la matriz de dependencias en formato CSV.
2. Seleccione el número de particiones `k` entre 2 y 5.
3. Presione `Ejecutar particionamiento`.
4. Revise los resultados: grupos, valor de corte y aristas cortadas.

## Formato de la matriz
- Matriz cuadrada
- Simétrica
- Valores no negativos
- Diagonal con ceros
